## How these documents were produced (honest note)

SAGA was built *before* these documents were written up in course format. They were
reconstructed afterwards from the evidence that exists:

- the original product briefing (19.08.2026) and the repository README,
- dated client decisions recorded in code comments ("CEO 08.09: …"),
- the commit history and deploy logs,
- the transcripts of the Claude Code build sessions (Sept–Oct 2026).

Where a fact could not be found in that evidence it is marked **[TBC]** instead of
being invented. That rule ("never invent facts — leave a placeholder") is also one of
SAGA's own product rules.

## Data protection in these documents

This folder lives in a public repository. All people, organisations and e-mail
addresses are therefore **fictionalised**. Real customers appear as personas
(e.g. "Chris, independent financial adviser"), the corporate pilot client as
"the Client (a financial-services group)". No server addresses, keys or customer
data are included.
